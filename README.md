# claude-motion-showreel

A fully procedural 15-second motion-design showreel — every frame and every
sound is generated by code, no assets, no keyframes, no video editing tools.

- `reel.py` — all visuals. Pure pycairo + PangoCairo at 1080p60, scenes keyed
  to an absolute timeline at 120 BPM (beat = 0.5s). Custom cubic-bezier
  easing, multi-sample motion blur, typography-driven scenes.
- `audio.py` — beat-synced soundtrack synthesized with the Python standard
  library only (kick, hats, bass, risers, reverb send), hits aligned to the
  same 120 BPM timeline.
- `render.py` — render driver. Parallel frame rendering via
  `multiprocessing`, piped straight into ffmpeg.

## Requirements

- Python 3 with `pycairo` and `PyGObject` (PangoCairo bindings)
- `ffmpeg` on PATH

## Usage

```bash
# Fast design check: contact sheet of stills at given seconds -> out/sheet.png
python3 render.py sheet 1.0 2.5 5.0 7.5

# Full 1080p60 render with 8-sample motion blur + audio -> out/showreel.mp4
python3 render.py video --samples 8
```
